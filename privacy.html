Mantra Hearth 🪔 · Privacy Policy

Effective 8 November 2026

Who we are

Mantra Hearth is a devotional chant channel on YouTube, Instagram and TikTok (@MantraHearth). The "Mantra Hearth" Google application exists only so that the channel's own owners can manage their own YouTube channel: upload videos, add captions, read channel statistics.

What the application accesses

The application signs in only with the channel's own Google account. It reads that channel's videos and statistics and writes to that channel's videos (uploads, captions, titles, playlists). It is not offered to the public and has no other users.

Data about visitors

This website is a static page hosted on GitHub Pages. We do not run analytics scripts, set cookies or collect personal data from visitors. GitHub may log standard web-server information; see GitHub's privacy statement. Links to Shopee are affiliate links; what happens on Shopee is governed by Shopee's own policy.

Google user data

Any Google user data the application receives (channel statistics, video metadata) is used only to operate and improve the Mantra Hearth channel. It is stored on the channel owners' own computers, is not sold, shared or transferred to anyone else, and is not used for advertising. Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
